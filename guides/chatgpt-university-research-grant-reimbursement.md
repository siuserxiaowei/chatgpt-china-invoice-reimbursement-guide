## 一、高校财务退单的 3 个高频原因

1. **提交境外英文账单**：OpenAI 官方仅提供英文 PDF Receipt，无中国大陆增值税发票号，绝大多数高校财务处直接退单。
2. **发票类目不符科研经费科目**：科研经费（国自然/省自然/横向课题）通常对应“测试化验加工费 / 信息服务费 / 技术服务费 / 算力服务”，开成“办公用品”会被审计拦截。
3. **缺少公务卡刷卡记录或对公凭证**：按高校规定，个人垫付需绑定本人公务卡支付并保留消费截图，大额采购需走学校对公转账并附合同。

## 二、4 步搞定高校科研经费报销

1. **下单前确认两件事**：询问院系科研秘书是否需要信息办前置审批，以及财务认可的发票类目（如 `*生产生活服务*技术服务费`、`*信息技术服务*算力服务`）。
2. **选择 0 加点国内数电普票方案**：1–4 席课题组自用可将公务卡绑定支付宝付款，确保付款金额与国内数电普票金额完全一致（三单同额）。
3. **全程免密保护未发表论文与实验数据**：拒绝任何索要账号密码或 Session JSON 的低价渠道，避免学术数据泄露或封号。
4. **备齐报销四件套提交财务**：
   - 国内数电增值税普通发票（PDF / OFD）
   - 公务卡 / 支付宝同金额付款凭证
   - 采购说明 /《服务费用结算证明》（大额附当天盖章合同）
   - ChatGPT 账号 `My Plan` 生效截图（作为交付验收证明，切勿混交美元英文 Invoice）
