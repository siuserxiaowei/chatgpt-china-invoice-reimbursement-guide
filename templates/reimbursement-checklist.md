# 企业与个人 ChatGPT 订阅报销材料自查清单

在提交 OA 报销单或高校财务报账前，请逐项勾选核对：

## 1. 票据要素核对
- [ ] **发票类型**：个人/小额（1–4 席）选国内数电增值税普通发票；一般纳税人集中采购（如 5 席+）选 **6% 增值税专用发票**
- [ ] **购买方抬头**：与营业执照/学校法人证书全称 100% 一致
- [ ] **纳税人识别号**：18 位统一社会信用代码无误
- [ ] **开票项目**：按真实业务核对（如 `*生产生活服务*技术服务费`、`*信息技术服务*算力服务`、`*信息技术服务*云计算服务`、`*信息技术服务*软件开发服务`），**非办公用品/餐饮等无关类目**
- [ ] **验真通过**：已通过全国增值税发票查验平台核验发票代码/号码与金额

## 2. 资金与三流合一核对
- [ ] **个人垫付/公务卡**：保留支付宝账单详情截图 + 银行卡/公务卡扣款记录，金额与数电发票 100% 一致
- [ ] **企业/高校对公**：对公银行回单收款方与发票销售方、合同盖章方三者完全一致
- [ ] **避免混交美元账单**：未将 ChatGPT 账号内美元 Invoice 混入人民币报销附件

## 3. 交付验收材料核对
- [ ] 附订单确认单或《服务费用结算证明》
- [ ] 附账号 `Settings → My Plan`（或 Codex CLI `/status`）生效状态截图
- [ ] 如为批量采购，附盖章采购合同及验收清单
